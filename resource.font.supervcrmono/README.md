# Super-VCR Mono

A pixel font based on the on-screen displays of VHS players and VCRs, by ASmolBoy
(https://twitter.com/AVerySmolBoy), from https://www.dafont.com/super-vcr-mono.font.

The font is licensed under the Creative Commons Attribution 4.0 International licence (CC BY 4.0),
included as LICENSE.txt.

Changed from the original: each letter was drawn as one square per pixel, and those squares are
merged into a single outline here, so the letters render without faint seams between the rows.
The shapes and spacing are the same.

Skins and add-ons can use it by these names: `supervcrmono24`, `supervcrmono36`, `supervcrmono40`,
`supervcrmono48`, `supervcrmono60` and `supervcrmono72`. Sizes that are a multiple of 12 keep its pixels square.
